Installation
============

Install from PyPI:

.. code-block:: bash

   pip install pureapi

Install for local development:

.. code-block:: bash

   git clone https://github.com/MarkHoo/pureapi.git
   cd pureapi
   python -m pip install -e ".[dev]"

Run the test suite:

.. code-block:: bash

   python -m pytest

Build a distribution package:

.. code-block:: bash

   python -m build
