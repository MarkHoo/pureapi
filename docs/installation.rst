安装
====

从 PyPI 安装：

.. code-block:: bash

   pip install pureapi

开发环境安装：

.. code-block:: bash

   git clone https://github.com/MarkHoo/pureapi.git
   cd pureapi
   python -m pip install -e ".[dev]"

运行测试：

.. code-block:: bash

   python -m pytest

构建分发包：

.. code-block:: bash

   python -m build
